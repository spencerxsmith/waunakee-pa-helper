Connect to the PA

  1. 1
    Connect the phone

    Use a wired adapter or audio interface when possible. Bluetooth is fine for non-timing-critical cues.

  2. 2
    Start low

    Set the mixer input low, phone hardware volume around 70%, then raise carefully.

  3. 3
    Run the test

    Tap the test above and confirm the sound comes from the PA—not the phone speaker.

Whistle and buzzer: use only when venue staff approves them. They can be confused with official signals.
